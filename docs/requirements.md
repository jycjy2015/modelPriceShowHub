# 需求规格说明

## 1. 背景与目标

系统用于维护大模型 API、资源方案和相关报价，提供公开查询、匿名比价、访客报价单，以及登录后的运营管理能力。参考交互来自 `temp/服务商管理台.html`，但正式数据不从该文件导入。

第一版目标是建立一个可在 Cloudflare 上运行的轻量管理后台：运营人员可以维护服务商和产品，超管可以维护账号并查看审计日志，访客只能看到已发布的对外信息。

## 2. 角色与权限

### 2.1 访客（未登录）

- 查看已发布且有对外展示价的产品。
- 按关键词、模型、品牌、来源、产品线等公开字段搜索和筛选。
- 使用匿名的跨服务商比价，只展示方案信息，不展示服务商身份。
- 生成参考报价单：只能使用对外展示价，不能改价；客户信息只在浏览器本地参与生成。
- 预览公开 PDF；下载按钮由 PDF 版本配置决定，但隐藏按钮不代表技术上禁止保存。
- 不得访问成本价、内部参考价、内部资源、运营备注、用户、会话或操作日志。

### 2.2 运营人员

- 登录后查看三层价格和全部内部运营字段。
- 新增、编辑、发布、停用和恢复产品 PDF 历史版本。
- 新增、编辑和停用服务商。
- 在产品表单内维护模型、品牌、来源、产品线字典。
- 使用对外展示价生成报价单，并临时调整本次报价；临时价格不回写产品。
- 维护自己的个人报价资料；不能查看操作日志，也不能管理用户。

### 2.3 超管

- 拥有运营人员的全部业务权限。
- 创建、启用、停用和重置普通运营人员或其他超管账号。
- 不能停用或删除最后一个有效超管。
- 查看完整操作日志，并按时间、用户、操作类型、对象类型和结果筛选。
- 按时间范围直接清理日志；清理不可恢复，清理动作本身必须留摘要日志。

## 3. 账号与登录

- 初始部署通过环境变量创建首个超管，不设置固定默认账号密码。
- 用户名创建后不可修改，必须全局唯一；账号只能停用，不能永久删除，也不能复用停用账号的用户名。
- 密码首期最低 8 位，不强制字母/数字组合，不做失败锁定；密码只保存哈希。
- 首次登录或被超管重置密码后必须修改密码。
- 会话有效期 30 天；退出、修改密码、重置密码或停用账号时撤销相关会话。
- 会话使用 `HttpOnly`、`Secure`、`SameSite` Cookie；管理后台与公开站点使用不同域名入口。

## 4. 产品、服务商与价格

### 4.1 产品状态

| 状态 | 行为 |
| --- | --- |
| 草稿 | 仅登录用户可见，不出现在公开搜索、匿名比价或公开 PDF 入口。 |
| 已发布 | 出现在公开站点；产品信息和对外价格修改后立即同步。 |
| 停用 | 不再公开，但记录、PDF 历史版本和日志保留。 |

新增产品默认草稿。产品可在没有 PDF 的情况下发布。服务商停用时，其关联产品自动停止公开；重新启用服务商不会自动重新发布产品。

### 4.2 字段范围

公开字段：

- 模型、品牌、来源（海外/国产/自研）、产品线。
- 公开名称、公开简介。
- 对外展示价区间、币种、计价单位。
- 参考 TPM、质保/服务说明。
- 当前公开 PDF 版本。

内部字段：

- 服务商、内部资源名称、等级、运营备注。
- 供应商成本价、内部参考/销售价。

模型、品牌、来源和产品线为数据库字典。普通运营人员和超管都可以在产品表单内新增、改名和停用字典项；改名会同步影响已关联产品，但历史日志快照不重写。被产品引用的字典项只能停用，不能永久删除。币种和计价单位使用系统预设。

### 4.3 三层价格

- 供应商成本价、内部参考/销售价、对外展示价分别保存最低价和最高价。
- 单值价格用最低价=最高价表示；最多保留 4 位小数，展示时去掉末尾无意义的 0。
- 发布前必须填写对外展示价和内部参考价；供应商成本价可以为空。
- 对外展示价不能清空；内部参考价和成本价可以为空。
- 对外折扣率按百分比展示，例如 `0.75` 显示为 `75%`。
- 不同币种或计价单位的产品不参与同一价格比较，不做汇率换算。

## 5. PDF 资料

- 每个产品可以有多个 PDF 历史版本，实际文件存储在 R2，版本元数据存储在 D1。
- 仅允许 PDF，单文件最大 50 MB；服务端校验扩展名、`Content-Type` 和文件头。
- 上传前必须勾选“已确认文件适合公开展示”。正文是否包含敏感信息由上传运营人员负责，系统不自动脱敏。
- 已发布产品上传新 PDF 后立即成为当前公开版本；公开页面只显示当前版本。
- 每个版本默认显示下载按钮，运营可以关闭；恢复历史版本时沿用该版本的下载设置。
- 运营人员和超管都可以恢复任意历史版本。
- PDF 文件和历史版本不允许删除；可撤下公开状态。产品永久删除后，PDF 仍保留但不再公开访问。
- 产品停用或 PDF 撤下后，Worker 拒绝后续公开访问，并使相关缓存失效。

## 6. 搜索、比价与报价单

- 公开搜索和后台产品列表均分页，默认每页 20 条，可切换 20/50/100 条。
- 公开搜索默认按最后更新时间倒序；同一时间按产品 ID 稳定排序。
- 公开匿名比价按相同模型、产品线、币种和计价单位分组，默认按对外最低价排序；结果不显示服务商。
- 运营比价可以显示真实服务商及三层价格。
- 运营报价单默认使用对外展示价，可临时调整价格；调整不保存回产品。
- 访客报价单只能使用对外展示价，不可改价，标注“系统参考报价，最终价格及服务条款以商务确认为准”，不显示供方签章栏或真实供方信息。
- 报价单正文、客户信息和临时报价不入库；运营端只记录生成事件，访客端完全在浏览器中生成。
- 报价单以 HTML 下载，并通过浏览器打印/另存为 PDF；Worker 不生成或保存报价文件。
- 每个运营账号维护自己的供方名称、品牌、联系人、电话和邮箱等报价资料；本人可维护，超管可代改，均记日志。运营报价单生成动作记录事件摘要，不保存报价正文。

## 7. 审计日志

- 记录登录、退出、改密、重置密码、用户变更、服务商变更、产品变更、价格变更、发布/停用、PDF 上传/恢复/撤下、字典变更、报价单生成和日志清理。
- 日志字段包括用户 ID、角色、用户名快照、操作类型、对象类型/ID、变更差异或摘要、时间、结果、请求 ID、IP 和 User-Agent。
- 不记录密码、会话令牌、PDF 正文、报价单客户信息和完整报价正文。
- 只有超管可查询完整日志；普通运营人员不显示入口且 API 拒绝访问。
- 超管可按时间范围直接清理日志，清理前二次确认；不提供强制导出或自动备份。

## 8. 非目标（第一版不做）

- 不导入参考 HTML 的演示数据。
- 不做 CSV/Excel 批量导入导出。
- 不做独立 PDF 资源中心。
- 不做独立仪表盘、复杂报表或报价单历史保存。
- 不做可视化细粒度权限配置和按服务商/产品线的数据范围限制。
- 不做服务商永久删除、用户永久删除或 PDF 文件删除。
- 不做实时汇率换算、强制 Turnstile 和服务端 PDF 报价单生成。
